# themes

One file per flavor, named after it: `forest.[ext]`, `jade.[ext]`, `mint.[ext]`.

Use the colors in [`../palette.json`](../palette.json) by role, as described in the [porting guide](https://github.com/Nephrite-theme/palette#building-a-port). If the app only supports one theme, start with Forest.

**Español:** un archivo por sabor, con su nombre: `forest.[ext]`, `jade.[ext]`, `mint.[ext]`. Usa los colores de [`../palette.json`](../palette.json) según su función, como explica la [guía para ports](https://github.com/Nephrite-theme/palette/blob/main/README.es.md#crear-un-port). Si la app solo admite un tema, empieza por Forest.
