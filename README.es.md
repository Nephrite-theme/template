## Contribuir

¿Un color que choca o poco contraste? [Abre un issue](../../issues/new/choose). Los colores salen de la [paleta Nephrite](https://github.com/Nephrite-theme/palette); para actualizarlos, ejecuta:

```sh
node scripts/sync-palette.mjs
```

Lee la [guía para contribuir](https://github.com/Nephrite-theme/.github/blob/main/CONTRIBUTING.es.md) para saber cómo se crean y revisan los ports de Nephrite.
