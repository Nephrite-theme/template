## Contributing

Found a color that clashes or low contrast? [Open an issue](../../issues/new/choose). Colors come from the [Nephrite palette](https://github.com/Nephrite-theme/palette); to update them, run:

```sh
node scripts/sync-palette.mjs
```

See the [contributing guide](https://github.com/Nephrite-theme/.github/blob/main/CONTRIBUTING.md) for how Nephrite ports are built and reviewed.
